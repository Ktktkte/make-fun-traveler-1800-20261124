Entry for the make.fun bounty [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb): one sentence, at most 200 characters, explaining the modern internet to someone arriving from the year 1800.

The sentence lives in `entry.txt`. Running `node main.ts` copies it to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
